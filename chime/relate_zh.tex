\section{相关工作}
\label{subs:motiv-related-work}

\myparagraph{用于 LLM 推理的 PIM/PNM 架构。}
除 AFD 系统中用于批量推理的 PIM 设计~\cite{park2024attacc,heo2024neupims}外，IANUS~\cite{seo2024ianus,li2025h2llm}采用不同的映射方法加速非批量推理。
针对长上下文场景，LoL-PIM~\cite{kwon2025lolpim}、CXL-PNM~\cite{park2024cxlpnm} 和 HPU~\cite{rhee2025hpu}提出可扩展的容量与带宽；DRM 可以指导这些系统的配置以获得最优性能。
Duplex~\cite{yun2024duplex}面向混合专家（MoE）推理。
由于 MoE 模型的 FC 层与稠密模型呈现相似的性能模式，DRM 可直接扩展用于分析 MoE 模型。
Papi~\cite{he2025papi}针对不同批大小，在多种 FC 设备上提出动态调度方法。
我们认为该工作与本文正交；这些设备对应 DRM 模型中的不同 Line-FC，并在低每秒请求数等若干真实场景中展现出较高的性能潜力。
CENT~\cite{gu2025cent}提出可扩展的纯 PIM 推理，可在多种场景中实现高性能。
但在 AFD 推理场景中，其 GDDR6-PIM 的成本效率会下降，如图~\ref{fig:motiv-memory-bottleneck} 所示。

\myparagraph{扩展 KV cache 容量的系统。}
FastDecode~\cite{he2024fastdecode}与 NEO~\cite{jiang2024neo}把 KV cache 卸载到主机内存，并由 CPU 计算 Attention。
InstAttention~\cite{pan2025instattention}利用 SSD 内部带宽，通过计算存储盘卸载 Attention。
如第~\ref{s:motiv-analytic-model} 节所分析，这些系统受限于 Attention 计算带宽。
CachedAttention~\cite{Gao2024cachedattention}、FlexGen~\cite{sheng2023flexgen}等工作使用主机内存存储 KV cache，再将其取回 GPU 进行 Attention 计算。
其延迟受 PCIe 带宽限制。

\myparagraph{仅使用 GPU 的 AFD 系统。}
部分既有工作在异构 GPU 上分离 Attention 与 FC~\cite{step3blog,step3system,zhu2025megascaleinfer}。
基于 DRM 的方法可以帮助它们更有效地平衡 Attention 与 FC 计算。
GPU 具有更强的通用性和软件兼容性，而 DIMM-PIM 则具有显著的成本优势。
