\section{Conclusion}
\label{s:conclusion}

This paper 
presents
the first general AFD performance model, Disaggregated Roofline Model, from which we conclude the ``Liebig's Law'' that guides the design of \sys,
a hardware-software co-designed AFD system with DIMM-PIM that offers scalable memory capacity and bandwidth for LLM inference.
\sys can enable efficient DIMM-PIM attention computation and maximizes the resource utilization for cross-device inference.
Evaluations show \sys achieves significantly higher throughput, establishing a new paradigm for efficient long-context LLM inference.
