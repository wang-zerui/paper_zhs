\section{引言}
大语言模型（LLM）~\citep{achiam2023gpt, touvron2023llama2, zeng2022glm, glm2024chatglm, team2023gemini, guo2025deepseek, bai2023qwen, yang2025qwen3} 极大拓展了人工智能能力的广度与深度，推动人们重新深入审视对机器智能的认识。
在所有应用场景中，基于 LLM 的 GUI（图形用户界面）智能体尤其受到研究者关注~\citep{xi2023rise,wang2023survey,liu2023agentbench}；这类智能体能够在用户设备上独立完成感知、推理与复杂任务执行。鉴于桌面环境仍是智能密集型任务的核心载体，开发计算机使用智能体对于从根本上改变人机交互方式并提升 AI 能力至关重要~\citep{agashe2025agent, wu2024copilot}。

尽管此前已有多项开发计算机使用智能体的尝试~\citep{agashe2025agent, lei2024infant, xie2025scaling}，使其在真实场景中长时间自主运行仍是一项重大挑战。第一个主要障碍源于 GUI 在本质上是为人类交互设计的，因此，让 GUI 智能体~\citep{liu2024autoglm,cua2025,qin2025ui} 模拟人类动作并非易事，而且过程繁琐。
第二，当前主流的行为克隆（BC）~\citep{bain1995framework, bratko1995behavioural} 方法，包括人工标注~\citep{he2025efficient}与模型蒸馏~\citep{sun2024genesis,xu2024aguvis}，在可扩展性与有效性方面均受到限制。人工标注虽然精确，但面对复杂任务时需要高得难以承受的人力成本。另一方面，模型蒸馏受限于教师模型的性能，因而限制了整体能力。这两类方法通常都表现出较差的泛化能力与有限的错误恢复能力。
最后，尽管强化学习（RL）已在桌面自动化任务中展现潜力~\citep{lu2025arpo, feng2025group}，其实际应用仍受计算复杂度与方法挑战所限。复杂环境、缓慢收敛以及 RL 训练中已知的低效率问题~\citep{xie2024osworld, bonatti2024windows, yu2025dapo, fu2025areal}，严重阻碍了其在计算机使用智能体训练中的大规模采用。

在本工作中，我们提出 \computerrl，这是一套端到端算法框架，旨在推进桌面级规划、推理与设备操作。该框架包含一种新的 API-GUI 交互范式、一套面向计算机环境的可扩展 RL 训练基础设施，以及一种能够延长有效训练过程的 RL 算法。
首先，我们提出 \actionmethod：一个大规模、自动构建的 API 生态系统，使智能体能够超越面向人类的操作范式所带来的固有偏置。
它采用更面向机器的设备交互方式，将 API 调用与 GUI 动作结合，从而显著提升智能体的通用性与整体性能。
其次，我们开发了一套基于 Docker 和 gRPC 协议的虚拟机集群分布式训练基础设施，以实现可扩展性，并与 AgentBench~\citep{liu2023agentbench} 完全兼容。该基础设施支持\textbf{数千个并行环境}，确保系统具备高度可扩展性，并使各环境的交互保持一致。此外，我们将训练基础设施与 AgentRL 框架~\citep{zhang2025model}集成，以支持高效的异步训练，从而加速训练过程。
最后，为应对 RL 训练中的停滞与收敛问题，尤其是熵坍缩和 KL 散度上升，我们提出 \rlmethod，周期性地在 RL 阶段与 SFT 阶段之间交替。该方法能够维持探索能力，并确保性能持续提升（图~\ref{figs:trending-right}）。

因此，通过在桌面环境中利用端到端 RL 与优化，\computerrl 在理解和操作 GUI 方面取得了显著进步。OSWorld 基准~\citep{xie2024osworld}上的评测表明，\computerrl 在计算机使用挑战中取得显著提升（见图~\ref{figs:success_rate}），成功率达到 \textbf{48.9\%}（RL 带来 66\% 的性能增益），超过 OpenAI CUA o3（42.9\%）、UI-TARS-1.5（42.5\%）和 Anthropic Claude Sonnet 4（30.7\%）等其他最先进模型。

概括而言，我们的贡献如下：
\begin{itemize}[leftmargin=*,itemsep=0pt,parsep=0.2em,topsep=0.2em,partopsep=0.0em]
    \item 我们提出一种新的交互范式：通过引入与传统 GUI 操作相结合的大规模自动构建 API 生态系统，使交互从以人为中心转向面向机器。该方法解决了人为设计的界面与人工智能体能力之间固有的不匹配，同时在基于计算机的任务上实现了更高的操作效率与泛化性能。
    \item 我们通过重构虚拟机集群，为计算机使用智能体建立了一套大规模分布式 RL 基础设施；它凭借数千个并行环境和与 AgentBench 的无缝兼容，达到了前所未有的可扩展性，从而克服了长期限制基于 RL 的计算机使用智能体训练扩展实验规模的关键瓶颈，并使大规模智能体训练取得突破性结果成为可能。
    \item 我们提出 \rlmethod，这是一种新的训练方法，通过策略性地交替 RL 与 SFT 阶段，系统解决长时间 RL 训练中的熵坍缩与 KL 散度累积问题，从而实现持续的性能提升，并在计算机自动化任务中达到最先进性能。
\end{itemize}
