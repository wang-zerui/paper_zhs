\section{Conclusion}
In this work, we present \computerrl, a novel computer use agent framework that advances desktop automation through the integration of API-based and GUI actions, efficient data collection, and scalable RL training. Our experiments on OSWorld and OfficeWorld demonstrate superior reasoning, accuracy, and generalization compared to prior approaches. 
This work lays the groundwork for more capable and persistent autonomous computer use agents, highlighting promising directions for future research in intelligent human-computer interaction.
