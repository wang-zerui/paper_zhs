\section{相关工作}

\vpara{大语言模型。}
GPT-4~\citep{achiam2023gpt}、Gemini~\citep{team2023gemini}、Claude-3~\citep{claude2}、Llama~\citep{touvron2023llama}、ChatGLM~\citep{zeng2022glm,du2022glm}、Qwen~\citep{bai2023qwen,team2024qwen2}和 DeepSeek~\citep{liu2024deepseek,guo2025deepseek}等 LLM 在知识表示与自然语言理解方面展现了卓越能力，推动了多样化的下游应用。
视觉语言模型（VLM）~\citep{hong2023cogagent,hong2025glm,bai2023qwen-vl,hurst2024gpt}进一步将 LLM 扩展到多模态输入，使模型能够对文本与图像进行联合推理，以完成视觉问答等任务。

\vpara{计算机使用智能体。}
CogAgent~\citep{hong2023cogagent}引入了多模态 GUI 理解能力。AutoGLM~\citep{liu2024autoglm}将规划与定位解耦，并通过在线 RL 加以改进。OS-Atlas~\citep{wu2024atlas}提出一种基础 GUI 动作模型。Aguvis~\citep{xu2024aguvis}通过视觉训练实现跨平台交互。PC-Agent-E~\citep{he2025efficient}使用轨迹增强来提高熟练度。UI-TARS~\citep{qin2025ui}根据屏幕截图执行类人的 GUI 交互。Agent S2~\citep{agashe2025agent}将定位与层次化推理结合。CUA~\citep{cua2025}提供可编程的桌面自动化能力。

\vpara{计算机使用基准。}
WebArena~\citep{zhou2023webarena}为在线交互提供模拟网站，但存在两方面局限：与真实环境有差异，而且只关注 Web。其他专注 Web 的基准~\citep{yao2022webshop,koh2024visualwebarena,chezelles2024browsergym,miyai2025webchorearena}也存在类似问题。软件工程基准~\citep{jimenez2023swe,yang2024swe,li2024devbench,zan2025multi,padigela2025ml}则缺少全面的桌面评测。
OSWorld~\citep{xie2024osworld}通过 369 项任务与 134 个评估函数弥补了这些空白。Windows Agent Arena~\citep{bonatti2024windows}进一步扩展了该方向，提供 150 多项基于 Windows 的任务。

\vpara{面向 LLM 的 RL 训练。}
PPO~\citep{schulman2017proximal}解决了 RL 训练中策略梯度不稳定的问题。GRPO~\citep{guo2025deepseek}通过组采样扩展 PPO，并移除了价值更新。DAPO~\citep{yu2025dapo}对 GRPO 进行改进，以提高稳定性。ARPO~\citep{lu2025arpo}引入回放缓冲区与任务选择机制。ZeroGUI~\citep{yang2025zerogui}利用 VLM 自动生成任务并估计奖励。Verl~\citep{sheng2025hybridflow}提出用于动态调度的混合编程方法。AReaL~\citep{fu2025areal}通过将模型生成解耦来实现异步 RL。
