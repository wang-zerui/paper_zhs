\begin{abstract}
我们提出 \computerrl，这是一套面向自主桌面智能的框架，使智能体能够熟练操作复杂的数字工作空间。\computerrl 采用 \actionmethod 范式，将程序化 API 调用与直接 GUI 交互统一起来，以解决机器智能体与以人为中心的桌面环境之间固有的不匹配问题。
扩展端到端强化学习（RL）训练，对于提升智能体能力以及在多样化桌面任务上的泛化能力至关重要；然而，由于环境效率低下，以及长时间训练过程中的不稳定性，这一目标仍然难以实现。
为了支持可扩展且稳健的训练，我们开发了一套分布式 RL 基础设施，可编排数千个并行虚拟桌面环境，从而加速大规模在线 RL。
此外，我们提出 \rlmethod，这是一种在强化学习与监督微调之间交替进行的训练策略，可有效缓解长时间训练过程中的熵坍缩。
我们将 \computerrl 应用于开放模型 \glm 与 \glmv，并在 OSWorld 基准上进行评测。\model-9B 达到了新的最先进准确率 \textbf{48.9\%}，表明通用智能体在桌面自动化方面取得了显著提升。
我们的代码与新基准 \textsc{\textbf{OfficeWorld}} 已发布于\href{https://github.com/thudm/ComputerRL}{我们的 GitHub 仓库}。
该算法与框架也被用于构建 \textsc{\href{https://autoglm.zhipuai.cn}{AutoGLM}}~\citep{liu2024autoglmautonomousfoundationagents}。
\end{abstract}
