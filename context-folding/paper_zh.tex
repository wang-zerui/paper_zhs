\abstract{
大语言模型（LLM）智能体在长程任务中从根本上受到上下文长度的限制。我们提出\textbf{上下文折叠}（Context Folding）框架，使智能体能够主动管理其工作上下文：智能体可按过程分支到一条子轨迹以处理子任务，在完成后将其折叠，压缩中间步骤，同时保留结果的简洁摘要。为使这一行为可学习，我们开发了端到端强化学习框架 FoldGRPO，并设计专门的过程奖励，以鼓励有效的任务分解和上下文管理。在复杂长程任务（深度研究和软件工程）上，我们的折叠智能体在保持相当或更优性能的同时，使用的活跃上下文比 ReAct 基线小 $10\times$，并显著优于依赖摘要式上下文管理的模型。
}
