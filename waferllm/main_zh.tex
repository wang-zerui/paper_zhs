\begin{abstract}
新兴 AI 加速器日益采用晶圆级制造技术：它们以网格架构集成数十万个 AI 核心，同时提供大容量的分布式片上内存（总计数十 GB）和极高的片上内存带宽（数十 PB/s）。然而，现有 LLM 推理系统针对 GPU 等共享内存架构进行了优化，无法充分发挥这些加速器的能力。

本文提出首个晶圆级 LLM 推理系统 \sys。\sys 由一种新的 PLMR 模型（读作“Plummer”）指导，该模型刻画了晶圆级架构独特的硬件特性。在这一模型的指导下，\sys 首创晶圆级 LLM 并行方案，以优化数十万个片上核心的利用率。系统还提出 \gemm 和 \gemv，这是首批面向晶圆级加速器、能够有效扩展的 GEMM 与 GEMV 实现。

评测表明，与最先进方法相比，\sys 的加速器利用率最高可提升 $200\times$。在晶圆级加速器 Cerebras WSE-2 上，\sys 的 GEMV 运算速度比 NVIDIA A100 GPU 快 $606\times$，能效高 $16\times$。对于完整 LLM 推理，\sys 相比运行 SGLang 和 vLLM 的 A100 GPU 集群取得 $10$--$20\times$ 加速。随着晶圆级 AI 模型、软件和硬件不断成熟，这些优势有望进一步扩大。\sys 已在 \href{https://github.com/MeshInfra/WaferLLM}{https://github.com/MeshInfra/WaferLLM} 开源。
\end{abstract}
