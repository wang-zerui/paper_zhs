\section{预备：让 LLM 冷启动长链式思维链}
我们首先验证：LLM 是否能在训练初期就具备适合 Long CoT 学习的有效轨迹。我们考察三种数据来源：强推理模型蒸馏、弱指令模型结合上下文学习（ICL）的蒸馏，以及基于人类推理轨迹的微调。\vspace{-5pt}

\paragraph{\textbf{只有来自强推理 LLM 的蒸馏有效。}}
为挑选有效数据源，我们构建了三个不同来源的推理轨迹集合。图~\ref{fig:comparison} 显示，只有来自强推理 LLM 的蒸馏数据，才能让学生模型学到并保持 Long CoT 结构，并在需要长程推理的基准上带来显著提升。这表明，只有高质量的轨迹才能可靠地支持 Long CoT 结构的学习与使用。\vspace{-8pt}




\paragraph{\textbf{基于弱指令 LLM 随机 ICL 的蒸馏无效。}}
缺乏显式推理训练的指令模型，与专门面向推理优化的模型存在明显差距。我们测试：能否通过从指令 LLM 蒸馏随机 ICL 提示下的解答来获得 Long CoT 结构。图~\ref{fig:comparison} 显示，模型性能显著下降。指令 LLM 最多只能模仿 6--8 步的短 CoT，在延展推理链条时无法同时保持中间步骤与轨迹连贯性。这说明 ICL 蒸馏更像是浅层模仿，而非稳健的长链推理学习。\vspace{-8pt}


\paragraph{\textbf{即便是类似 Long CoT 的人类标注轨迹也无法奏效。}}
受 \citet{du2025the} 启发，我们进一步测试：人类逐步书写的解题思路能否诱导模型学到 Long CoT。我们采集复杂推理任务的人类解答，并用其微调模型。图~\ref{fig:human} 表明，使用人类轨迹训练并没有复现强推理模型蒸馏带来的长链收益。这意味着，人类解法固然有助于局部求解，但未必能可靠地编码保障长程推理分布所需的抽象能力。

\begin{TakeawayBox}{结论 1}
从强推理 LLM 蒸馏能够有效传授 Long CoT 结构；而依赖弱指令模型的 ICL 或人类轨迹微调只能带来有限收益。这凸显了高质量推理范例对于稳健长链学习的重要性。
\end{TakeawayBox}
