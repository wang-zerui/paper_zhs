## Notes

- 中文题目：Agentic Harness Engineering：由可观测性驱动的 Coding Agent Harness 自动演化
- 原文：[arXiv:2604.25850](https://arxiv.org/abs/2604.25850)
- 核心内容：把 coding agent 的 harness 拆成文件级可编辑组件，用分层轨迹证据语料驱动演化智能体逐轮编辑，并要求每次编辑附带可在下一轮验证的预测，从而让 harness 自主演化而非退化为试错；十轮迭代把 Terminal-Bench 2 的 pass@1 从 69.7% 提升到 77.0%，冻结后的 harness 可跨基准与跨模型家族迁移。
