## 内容说明

本文提出 ComputerRL，将自动构建的 API 与 GUI 操作统一到计算机使用智能体的动作空间中，并以数千个并行桌面环境和全异步 RL 基础设施扩展在线训练。作者还提出在 RL 与成功轨迹监督微调之间交替的 Entropulse 策略，以缓解长时间训练中的熵坍缩；其 AutoGLM-OS-9B 在 OSWorld 上报告了 48.9% 的成功率。

本译本逐句翻译摘要及全部六个正文章节，并保留公式、正文图表、引用和数值；附录在同一 PDF 中保留英文原文。
