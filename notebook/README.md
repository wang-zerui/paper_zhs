## 使用方式

1. 左侧目录直接进入单篇论文阅读页。
2. 每个阅读页都内嵌浏览器 PDF viewer，同时保留原始 PDF 打开入口。
3. 新增论文后运行 `python3 scripts/build_paper_notebook.py`，再执行 `npm run build:notebook` 即可刷新站点。
