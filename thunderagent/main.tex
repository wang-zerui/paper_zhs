\section{Conclusion}

% \vspace{-1mm}
We introduce \ouralg, a fast and simple agentic system built on a program-level abstraction that tracks metadata throughout the entire lifecycle of each agentic workflow. \ouralg leverages the program abstraction for runtime scheduling and resource management. Specifically, \ouralg dynamically schedules program execution across GPU nodes to mitigate KV cache thrashing and memory imbalance, while managing tool resources to prevent resource leakage. Experimental results showcase that \ouralg outperforms previous systems by \textbf{1.48--3.58}$\times$ for serving and \textbf{1.79--3.92}$\times$ for RL rollouts.
