\section{Experiments}
\label{sec:experiments}

PivotRL achieves larger in-domain gains than same-data SFT while nearly eliminating OOD degradation (in Section~\ref{sec:indomain_ood_sft}). On SWE-Bench, where end-to-end RL (E2E RL) is the standard training paradigm, PivotRL attains competitive accuracy without multi-turn environment rollouts (in Section~\ref{sec:swe_e2e}). An ablation confirms that both pivot filtering and functional reward are necessary for the full gains (in Section~\ref{sec:ablation_study}).

\paragraph{Setup.}
We train on four agentic domains---conversational tool use, software engineering, terminal control, and web browsing---and evaluate on the corresponding benchmarks: $\tau^2$-Bench~\citep{barres2025tau2bench}, SWE-Bench Verified~\citep{jimenez2024swebench}, Terminal-Bench~\citep{tbench_2025}, and BrowseComp~\citep{wei2025browsecompsimplechallengingbenchmark}. All experiments start from \texttt{Qwen3-30B-A3B-Thinking-2507} (hereafter ``Base''), use Nemo-RL~\citep{nemo-rl} for optimization, and Nemo-Gym~\citep{nemo-gym} for environment rollouts. For every SFT--PivotRL comparison, the base model, prompts, and expert trajectories are identical. Domain-specific data construction, verifier design, and hyperparameters appear in Appendix~\ref{app:training_details}.

\subsection{Comparison to End-to-End RL on SWE-Bench}
\label{sec:swe_e2e}

SWE-Bench is a natural comparison point because E2E RL is the standard training method for software-engineering agents: each GitHub issue requires a multi-turn tool-using trajectory, and the evaluation harness provides a binary success signal.

\begin{table}[t]
\centering
\small
\begin{tabular}{lcc}
\toprule
\textbf{Method} & \textbf{SWE Score} & \textbf{Average Rollout Turns} \\
\midrule
Base             & 19.07 & -- \\
Same-data SFT    & 37.40 & 0 \\
PivotRL          & 32.67 & 0 \\
E2E RL           & 37.00 & $10^2$ \\
\bottomrule
\end{tabular}
\caption{
SWE-Bench Verified results. \textbf{Rollout Turns} counts the average environment rollout turns during training. PivotRL uses only local verifier scoring and reaches $32.67$ without any environment rollouts, closing most of the gap to E2E RL ($37.00$).
}
\label{tab:swe_e2e}
\end{table}

All methods start from Base and are evaluated with the OpenHands harness~\citep{wang2025openhandsopenplatformai}. PivotRL requires no environment rollout turns---its single-turn completions are scored by a local verifier---yet reaches $32.67$, compared to $37.00$ for E2E RL which requires ${\sim}10^4$ environment turns.
