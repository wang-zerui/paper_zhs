我们提出 GLM-5，这是一款新一代基础模型，旨在将 ``vibe coding'' 范式推进到 ``agentic engineering''。
 在前代模型 Agentic、Reasoning 与 Coding（ARC）能力的基础上，GLM-5 采用 DSA，在保持长上下文保真度的同时显著降低训练与推理成本。为进一步提升模型对齐与自主性，我们实现了新的异步强化学习基础设施，通过将生成与训练解耦，大幅提升后训练效率。此外，我们提出了新型异步 Agent RL 算法，进一步提升 RL 质量，使模型能够更有效地从复杂、长时程交互中学习。凭借这些创新，GLM-5 在主要公开基准上达到最先进性能。更关键的是，GLM-5 在真实编码任务中展现出前所未有的能力，在处理端到端软件工程挑战时超越了此前基线。
