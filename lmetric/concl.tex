\section{Conclusion}
\label{sec:concl}

\noindent
We contribute the first multiplication-based combinator to achieve high-quality LLM request scheduling
by achieving both {\kvcache}-awareness and load balancing in a hyperparameter-free manner.
%Our approach effectively achieves two important objectives---being {\kvcache}-aware and achieving load balancing
%for LLM serving without any hyperparameter tuning.
Evaluations on real-world workloads covering chatbots, API calls, and coding agents
confirm the benefits of our approach over state-of-the-art methods including vLLM~\cite{vllm-code}, ai-Dynamo~\cite{ai-Dynamo}, llm-d~\cite{llm-d} 
and a production scheduler used in {\company}.
