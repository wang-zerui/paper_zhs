\section{Additional Related Work on Inference-Time Orchestration}
\label{ap:related}

Recent work on automatic MAS design typically operates at inference time and relies on a validation set to guide adaptation.  MASS~\citep{zhou2025multiagentdesignoptimizingagents} uses rejection sampling to select effective agent configurations, and MaAS~\citep{zhang2025multiagentarchitecturesearchagentic} extends MASS with a question-wise masking mechanism to adapt subnetworks. ADAS~\citep{hu2025automated} and AFlow~\citep{zhang2024aflowautomatingagenticworkflow} frame MAS design as a code generation task. ADAS stores and searches historical designs based on validation performance, while AFlow enhances this with Monte Carlo Tree Search. One exception is MAS-Zero \citep{Ke2025MASZero}, which performs fully inference-time automatic MAS design without relying on a validation set. However, these inference-time methods exhibit limited adaptability, as unreliable validation signals or incorrect guidance from LLM-based judges can misdirect the adaptation process.
