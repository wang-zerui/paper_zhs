\subsection{Correctness Computation}

For math correctness (AIME), we use string matching via Hugging Face’s Math-Verify.\footnote{\url{https://github.com/huggingface/Math-Verify}} For the other benchmarks, we use Llama-3.3-70B-Instruct \cite{grattafiori2024llama3herdmodels} as an LLM-as-a-judge to determine correctness.
