\begin{abstract}
多模态大语言模型的快速发展，为 GUI 自动化带来了前所未有的机会；但一个基础问题仍未解决：如何在保证标注可靠性的同时，高效获得高质量训练数据？本文提出以\textbf{校准式步骤奖励系统}（Calibrated Step Reward System, CSRS）为核心的自进化训练流水线。该系统通过轨迹级校准，将模型生成的执行轨迹转化为可靠训练信号，以 10--100 倍更低的成本实现超过 90\% 的标注准确率。

基于这一流水线，我们训练了 Step-GUI 系列 GUI 专家模型（4B/8B）。其中 Step-GUI-8B 在多项 GUI 基准上取得了领先结果，包括 AndroidWorld 80.2\%、OSWorld 48.5\%、ScreenSpot-Pro 62.6\%，并在我们提出的 AndroidDaily 上达到静态任务 89.91\%、端到端任务 52.50\% 的表现，同时保持较强的通用多模态能力。

随着 GUI 智能体能力增强，真实部署还面临两个现实问题：异构设备之间缺乏统一接口，以及敏感屏幕内容带来的隐私风险。为此，我们提出 \textbf{GUI-MCP}，这是首个面向 GUI 自动化的 Model Context Protocol。它采用分层设计，将底层原子操作与本地 GUI 专家模型支持的高层任务委派结合起来，从而在保证隐私的前提下实现高效执行。

最后，我们提出 \textbf{AndroidDaily}，这是一个基于真实移动端日常使用模式构建的评测基准，包含 3146 个静态动作样本与 235 个端到端任务。该基准更贴近日常高频移动场景，可用于评估 GUI 智能体在真实数字生活中的实用性。总体而言，本文从数据构建、模型训练、部署接口到真实评测，系统性推进了实用 GUI 智能体的发展。
\end{abstract}
