\begin{abstract}
LLM 代理越来越多地将技能作为一种可复用的组合单元。
尽管技能会在多种代理平台之间共享，现有系统却把它们当作原始上下文，致使同一技能在不同代理上表现不一致。
这种脆弱性损害了技能的可移植性与执行效率。

为应对这一挑战，我们分析了约 118,000 个技能，并从传统编译器设计中获得启发。
我们将技能视为代码，将 LLM 视为异构处理器。
为了使可移植性成为可操作的目标，我们把技能的需求分解为一组原语能力，
并衡量每个模型--代理框架组合对这些能力的支持程度。
基于这些能力画像，我们提出 \sys：一个面向可移植、高效技能执行的编译与运行时系统。
在编译时，\sys 执行基于能力的编译、环境绑定和并发性提取。
在运行时，\sys 通过 JIT 代码固化与自适应重编译来优化性能。

我们在规模各异的八个 LLM 和三个代理框架上评估 \sys，覆盖 SkillsBench 与具有代表性的技能任务。
结果表明，\sys 在不同模型和环境中显著提高了任务完成率，同时最多减少 40\% 的 token 消耗。
在性能方面，\sys 借助增强的并行性实现最高 3.2$\times$ 加速，并通过代码固化将延迟降低 19--50$\times$。
\end{abstract}
