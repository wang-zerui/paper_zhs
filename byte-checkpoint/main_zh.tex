\begin{abstract}
在大型基础模型（Large Foundation Models，LFMs）的开发过程中，为了在各类故障或 GPU 资源与 parallelism 配置变化后恢复训练，checkpointing 保存训练状态至关重要。
此外，保存的 checkpoints 会被分发到 evaluation 任务或在不同训练阶段之间转移（例如从 pre-training 到 post-training）。
这些场景都需要将分布式 checkpoints 从一种 parallelism 重新分片（resharding）到另一种。
在生产环境中，不同 LFM 会依据模型规模与训练规模采用不同的 training framework 和 storage backend。
因此，需要一个高性能的 checkpointing 系统，以在 LFM 全生命周期内实现大规模高效的 checkpoint 管理。

我们提出 \sys{}，一个面向大规模 LFM 训练的工业级 checkpointing 系统。
\sys{} 具备：与 parallelism 无关的 checkpoint 表示，可在加载时（load-time）高效 resharding；
面向多 training framework 与多 storage backend 的通用保存/加载 workflow；
保障高 I/O 效率与可扩展性的 full-stack 优化；
以及用于大规模性能分析与瓶颈定位的监控工具套件。
与现有开源 checkpointing 系统~\cite{torch-dcp, megatron-dcp} 相比，\sys{} 显著降低运行时 checkpoint stall，平均减少 54.20$\times$。
在保存与加载时间上，\sys{} 最高分别提升 9.96$\times$ 与 8.80$\times$。
\end{abstract}
