\subsection{预训练阶段}
\paragraph{Benchmarks} 我们在多个公开基准上评估 \modelname{} 基座模型，覆盖语言理解、问答、代码生成与数学求解等领域。评测以英文与中文数据集为主，并补充少量多语种基准以增强覆盖面。

\begin{itemize}[leftmargin=*]

\item 语言理解：使用 \textit{Hellaswag}~\cite{Zellers2019HellaSwagCA}、\textit{Winogrande} 评估语境推理；使用 \textit{DROP}~\cite{Dua2019DROPAR}、\textit{RACE}~\cite{Lai2017RACELR}、\textit{ARC}~\cite{Clark2018ThinkYH} 系列评估阅读理解；并结合 \textit{PIQA}~\cite{Bisk2019PIQARA}、\textit{Natural Questions}~\cite{Kwiatkowski2019NaturalQA}、\textit{TriviaQA}~\cite{Joshi2017TriviaQAAL} 评估知识检索能力。

\item 问答：包括中文知识基准 \textit{C-Eval}~\cite{Huang2023CEvalAM}，英文领域知识基准 \textit{MMLU}~\cite{Hendrycks2020MeasuringMM} 及其进阶版本 \textit{MMLU-Pro}~\cite{Wang2024MMLUProAM}，并使用 \textit{BigBenchHard}~\cite{Suzgun2022ChallengingBT} 评估复杂问题求解能力。

\item 代码生成与理解：采用 \textit{HumanEval}~\cite{Chen2021EvaluatingLL} 与 \textit{MBPP}~\cite{Austin2021ProgramSW} 评估标准代码生成任务，并使用 \textit{CruxEval}~\cite{Gu2024CRUXEvalAB} 评估代码理解与推理。

\item 数学推理：使用 \textit{CMath}~\cite{Wei2023CMATHCY}、\textit{GSM8K}~\cite{Cobbe2021TrainingVT} 评估基础算术与简单问题，\textit{MATH}~\cite{Hendrycks2021MeasuringMP} 评估高阶数学推理，\textit{MGSM}~\cite{Shi2022LanguageMA} 评估多语种数学求解能力。

\end{itemize}

\paragraph{Baselines \& Comparison Settings} 我们将 \modelname 与多个强基线比较，覆盖稠密模型（Qwen2.5-72B、Llama-405B）和 MoE 模型（DeepSeek-V3）。对于基座模型，大多数评测采用 few-shot，少数任务使用 zero-shot。多数基准通过与标准答案精确匹配打分，代码生成任务则采用执行验证。

\paragraph{Evaluation Results}
表~\ref{tab:main} 对比了 \modelname~预训练基座模型与其他主流模型。总体看，\modelname 在大多数英文通用基准和全部中文基准上达到最优。
在代码与数学任务上虽略低于 DeepSeek V3，但整体表现仍具竞争力。

进一步分析可见，\modelname~在中文基准上优势明显，不仅超过 Qwen 2.5 72B，也优于当前最强中文模型之一 DeepSeek V3。
此外，与 Llama 3.1 405B 相比，\modelname 在多数高难度基准上得分更高，而训练 FLOPs 仅约为 Llama 405B 的 29\%。

\subsection{消融研究}  
本节补充模型架构消融实验，并分析训练过程中的关键行为，以便更深入理解稠密 LLM 的训练特性。

\subsubsection{Depth-scaled Sandwich-norm} \label{sec:sandwich-ablation}
我们开展实验验证 depth-scaled sandwich norm 相比 pre-norm 架构的有效性。实验使用 130 亿参数稠密 Transformer，在相同超参数下训练 3000 亿 token，对两种配置进行对比。

图~\ref{fig:sandwich_compare} 显示，depth-scaled sandwich-norm 可以稳定梯度范数并有效消除 loss spike，从而加快训练收敛。
我们在两个组合基准上评估性能：EN basic（多个英文基准组合）和 ZH basic（中文基准组合）。此外，还使用 LAMBADA~\cite{Paperno2016TheLD}（英文）和 WPLC~\cite{Ge2021ChineseWA}（中文）next-token 预测任务进行补充验证。
结果清楚表明：在预训练阶段抑制 loss spike 对模型性能至关重要。

\subsubsection{\modelname 的层统计特性}

\paragraph{稳定的激活尺度}
图~\ref{fig:act_analysis} 展示了 Transformer 各层 attention 与 FFN 模块的激活模式，包括均值、标准差和 top-1 激活值。激活分布整体稳定：在保持清晰分层模式的同时，标准差在整个预训练过程中维持一致尺度。
我们观察到 ``super activations'' 现象：浅层中其幅值可达 $10^3$ 量级，这与 Llama 模型中的观察一致~\cite{Yu2024TheSW}。
值得注意的是，图~\ref{fig:act_analysis} 显示 top-1 激活值会随层深增加逐步下降，意味着其对最终输出的相对影响变小。

\begin{figure}[htbp]
    \centering
    \includegraphics[width=\textwidth]{fig/model_iter_7T_activation.pdf}
    \caption{attention 与 FFN 模块激活统计，包括均值、标准差和 top-1 值。每条曲线对应 1T、2T、4T、7T 不同训练 token 位置。"Std" 行显示跨层激活尺度稳定；"Top 1" 行显示 down projection 与 attention output projection 中存在 "super activations"，其量级处于合理范围，并与 LLaMA 中观察到的现象相当~\cite{Yu2024TheSW}。}

\paragraph{Depth-scaled sandwich norm 的逐层模式}

图~\ref{fig:gamma_analysis} 展示了各 sandwich-norm 层缩放参数 $\gamma$ 的分布，呈现以下关键现象：
四个 LayerNorm 的 $\gamma$ 参数在训练过程中均值/标准差均下降，与 weight decay 效应一致；
post-norm 的 $\gamma$ 呈明显层依赖模式：其标准差随层深增加而显著上升；
pre-norm 的 $\gamma$ 在层间保持相对恒定的标准差。
该模式揭示了一个有趣行为：浅层主要依赖残差连接，而深层随着缩放参数 $\gamma$ 幅值增大，逐步更依赖 Transformer 子层输出。
\begin{figure}[htbp]
    \centering
    \includegraphics[width=\textwidth]{fig/model_iter_7T_param.pdf}
    \caption{sandwich-norm 中 $\gamma$ 参数分布（均值与标准差）。每条曲线对应 1T、2T、4T、7T 不同训练 token 位置。两个 post-norm 呈现清晰逐层模式：$\gamma$ 的均值和标准差随深度增加而上升。更大的 post-norm $\gamma$ 表明深层更强调 Transformer 输出而非残差连接。}
    \label{fig:gamma_analysis}
\end{figure}
